# HLS

下面把 `docs/intro.md` 翻译成法语。

## 配置国际化

修改 `docusaurus.config.js`，添加对 `fr` 语言环境的支持：

```js title="docusaurus.config.js"
export default {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'fr'],
  },
};
```

## 翻译文档

将 `docs/intro.md` 复制到 `i18n/fr` 文件夹：

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

把 `i18n/fr/docusaurus-plugin-content-docs/current/intro.md` 翻译成法语。

## 启动本地化网站

以法语语言环境启动网站：

```bash
npm run start -- --locale fr
```

本地化网站可通过 [http://localhost:3000/fr/](http://localhost:3000/fr/) 访问，其中“开始使用”页面已经完成翻译。

:::caution

在开发环境中，一次只能使用一种语言环境。

:::

## 添加语言下拉菜单

要在不同语言之间顺畅切换，请添加语言下拉菜单。

修改 `docusaurus.config.js` 文件：

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        // highlight-start
        {
          type: 'localeDropdown',
        },
        // highlight-end
      ],
    },
  },
};
```

语言下拉菜单会显示在导航栏中：

![语言下拉菜单](./img/localeDropdown.png)

## 构建本地化网站

为指定语言环境构建网站：

```bash
npm run build -- --locale fr
```

也可以一次构建包含所有语言环境的网站：

```bash
npm run build
```
