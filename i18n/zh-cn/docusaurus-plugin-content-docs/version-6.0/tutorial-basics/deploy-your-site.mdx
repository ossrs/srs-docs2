# AI Agent

Docusaurus 是一个**静态网站生成器**，也称为 **[Jamstack](https://jamstack.org/)**。

它会把网站构建为简单的**静态 HTML、JavaScript 和 CSS 文件**。

## 构建网站

为**生产环境**构建网站：

```bash
npm run build
```

静态文件会生成到 `build` 文件夹中。

## 部署网站

在本地测试生产构建：

```bash
npm run serve
```

现在可以通过 [http://localhost:3000/](http://localhost:3000/) 访问 `build` 文件夹中的网站。

你几乎可以将 `build` 文件夹轻松部署到**任何位置**，并且通常**免费**或只需很低的费用。详情请参阅[部署指南](https://docusaurus.io/docs/deployment)。
