# 源码编译

Docusaurus 会为**每篇博客文章创建一个页面**，同时还会创建**博客首页**、**标签系统**和 **RSS** 订阅源等内容。

## 创建第一篇文章

创建文件 `blog/2021-02-28-greetings.md`：

```md title="blog/2021-02-28-greetings.md"
---
slug: greetings
title: 大家好！
authors:
  - name: Joel Marcey
    title: Docusaurus 1 联合创建者
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
  - name: Sébastien Lorber
    title: Docusaurus 维护者
    url: https://sebastienlorber.com
    image_url: https://github.com/slorber.png
tags: [问候]
---

恭喜，你已经完成了第一篇文章！

你可以自由尝试，并按照自己的想法修改这篇文章。
```

现在可以在 [http://localhost:3000/blog/greetings](http://localhost:3000/blog/greetings) 查看这篇新文章。
